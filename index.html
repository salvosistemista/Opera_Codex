Tema

Schermo intero

Nasconde la barra degli indirizzi e gli altri elementi del browser. Funziona su desktop e sulla maggior parte dei browser Android; il supporto su iOS/Safari è limitato.

Menu di navigazione (mobile)

Riordina le sezioni con le frecce e scegli se mostrare il testo sotto le icone, per recuperare spazio nella barra in basso senza invadere l'area dei gesti dello smartphone.

Dimensione copertine

Lato massimo a cui vengono ridimensionate le copertine caricate da file o da URL (compressione JPEG qualità 0.75). Vale solo per le copertine caricate da ora in poi.

Backup e Ripristino

Esporta l'intero database (Opere, Edizioni, Istanze, Sessioni di lettura, Schede Autore, impostazioni) in un file JSON, o importane uno per ripristinare/sostituire i dati attuali.

Backup Schede Autori

Esporta o importa solo le schede autore (biografia, foto, tematiche, impatto, opere collegate), indipendentemente dal resto del database. L'import qui è additivo: aggiorna le schede con lo stesso nome e aggiunge le altre, senza toccare Opere/Edizioni/Istanze.

Backup su Server WebDAV

Carica il backup completo (con copertine) direttamente su Nextcloud, ownCloud o qualunque server WebDAV. Nota: molti server WebDAV non permettono richieste dirette da pagine web (CORS) — se ricevi un errore di rete, verifica che CORS sia abilitato sul tuo server per l'origine di questa app.

Backup su Google Drive

Richiede un Client ID OAuth gratuito, creato da te su Google Cloud Console (tipo "ID client OAuth" → "Applicazione web", con l'origine da cui apri questa app tra quelle autorizzate). L'app userà solo il permesso "drive.file": può leggere/scrivere esclusivamente i file che crea lei stessa, non l'intero Drive.

⚪ Non connesso

Migrazione da OmniShelf

Importa una tantum i libri dal backup JSON di OmniShelf. Le Opere vengono aggiunte al catalogo attuale, non lo sostituiscono — se hai già inserito a mano alcuni di questi libri rischi doppioni: verifica prima di procedere.

⚠️ Zona pericolosa

Cancella tutto il database — ogni Opera, Edizione, Istanza e Sessione di lettura, ogni Scheda Autore, oltre a tutte le impostazioni (tema, ordine menu, dimensione copertine, credenziali WebDAV). È come ripartire da un'installazione nuova. Richiede doppia conferma perché non è reversibile: se vuoi un modo per tornare indietro, esporta prima un backup (JSON o WebDAV).
